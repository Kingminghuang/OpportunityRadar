# 去 AI 味规范（humanizer-zh）

> 去 AI 味规范与 24 类 AI 写作模式已全文抄录进仓库，供 `article-writer` 就地使用，不再依赖仓库外文件。

把文本改得像一个具体的人写的，而不是简单换同义词。目标是更直接、更有节奏、更符合原定声口，同时不扩张事实。

## 不可越过的边界

- 不新增数字、人物、引语、案例、来源、现场细节、亲历、采访、动机或结论。
- 不把不确定内容改成确定事实，不删除原文中的必要限定和来源边界。
- 不擅自改变立场、受众、文体和风险级别；正式报道不能被改成情绪化自媒体文。
- 保留标题层级、链接、引用、代码、表格和用户要求保留的结构。
- 若原文缺少支撑，不用“更具体”的虚构细节填空；改为删掉空泛主张或明确其不确定性。

## 先确定声口

按 brief 或原文选择，不把“人味”误解为一律使用第一人称：

| 模式 | 目标 |
|---|---|
| 正式报道 / 公共事件档案 | 克制、清楚、事实优先；情绪来自事实后果，不注入“我很愤怒”等表演性反应 |
| 观点 / 行业专栏 | 可保留第一人称和锋利判断；情绪必须钉在已知机制、成本或责任上 |
| 教程 / 技术说明 | 直接、准确、少铺垫；不强行加个性段落 |
| 普通编辑 | 匹配原文语气，只清理机器痕迹 |

`article-writer` 的贴图正文固定采用“观点 / 行业专栏”声口：口语化、像懂行的朋友在聊天，允许锋利判断，但情绪必须落在机制、成本或责任上。

## 一轮改写法

1. **锁定事实**：先标出数字、日期、专名、引语、来源、结论状态和必要限定，改写后逐项核对。
2. **删除空话**：删“值得注意的是”“标志着重要转折”“不断演变的格局”等不增加信息的句子。
3. **修正归因**：有明确来源就写来源；没有就删掉“专家认为”“多方指出”之类假权威，不自造出处。
4. **拆公式结构**：处理“不仅……而且……”“不是……而是……”、机械三段式、每节同构和“挑战与展望”模板。
5. **恢复自然节奏**：长短句交错，能用“是 / 有 / 可以”就不用绕弯结构；允许关键词自然重复，不做同义词循环。
6. **清理展示痕迹**：删聊天式开场、免责声明、讨好语、emoji、过多粗体、内联小标题列表和万能积极结尾。
7. **终检**：朗读一遍，检查事实未膨胀、立场未漂移、语气符合模式、段落不再像同一模板复制。

优先处理最影响阅读的句子，不为追求“变化”把每句话都改一遍。空洞金句应删；有事实或机制支撑的锋利判断可以保留。

## 快速检查

- 连续三句长度和结构相同：拆掉其中一句或合并两句。
- 一段里出现多个“此外、然而、同时、值得注意的是”：多数可直接删除。
- “从 A 到 B”不是同一尺度、“三项”只是为了凑完整：改为真实关系和真实数量。
- 破折号、括号、粗体和冒号列表抢过正文：减少展示性标记。
- 段尾总是口号、反问或一句金句：改成事实、代价、未决边界，或直接结束。
- 读起来很顺却没有任何可核验信息：删除或回到来源补证，不润色成更像真的话。

## 24 类 AI 写作模式

### 内容与归因

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 1. 夸大意义 | 标志着、见证了、关键转折、深远影响 | 写实际发生了什么；无新增信息就删除 |
| 2. 强调知名度 | 被多家媒体报道、广受关注 | 只保留与正文有关的一条具体报道或事实 |
| 3. 句尾伪分析 | 从而彰显、进一步体现、确保了 | 拆成可验证事实；没有事实就删掉尾巴 |
| 4. 宣传腔 | 开创性、充满活力、令人惊叹、卓越 | 换成可观察的功能、规模、时间或结果 |
| 5. 模糊归因 | 专家认为、业内指出、多方消息 | 写明来源和时间；无法确认就删除或标不确定 |
| 6. 挑战与展望模板 | 尽管面临挑战，未来仍然可期 | 写已经发生的限制、应对和仍未解决的问题 |

### 语言与结构

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 7. AI 高频词 | 此外、至关重要、赋能、格局、深入探讨 | 删连接词，换成普通动词和具体对象 |
| 8. 回避“是/有” | 作为、充当、拥有着、提供了一个 | 直接写“是、有、可以” |
| 9. 否定式排比 | 不仅……而且……；不是……而是…… | 直接陈述真正结论 |
| 10. 强凑三项 | 三个并列形容词、每处都分三点 | 使用事实需要的数量，不追求三段式 |
| 11. 同义词循环 | 主人公/核心人物/中心角色交替 | 用同一个准确称谓，合并重复句 |
| 12. 虚假范围 | 从 X 到 Y，但两者不是同一尺度 | 列出实际覆盖的项目或删除“从……到……” |

### 展示与排版

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 13. 破折号过多 | 每段都用“——”制造转折 | 改句号、逗号或真正的因果关系 |
| 14. 粗体过多 | 每句都有加粗短语 | 只保留少量真正需要扫读的关键词 |
| 15. 内联标题列表 | “**性能：**…… **安全：**……” | 能成段就成段；确属步骤时保留列表 |
| 16. 英文标题式大写 | Every Major Word Capitalized | 按目标语言和专名规则正常书写 |
| 17. Emoji 装饰 | 🚀、💡、✅ 充当小标题 | 删除；用正文关系表达层级 |
| 18. 引号混乱 | 中文正文混用不合语境的英文引号 | 按文体统一中文引号，代码和原始引文除外 |

### 对话残留与回避

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 19. 协作痕迹 | 当然、希望对你有帮助、请告诉我 | 删除，直接进入正文 |
| 20. 模型免责声明 | 截至训练时间、基于有限信息 | 换成真实来源边界；无来源则不要断言 |
| 21. 谄媚语气 | 好问题、你说得完全正确 | 删除评价，回应具体问题 |
| 22. 填充短语 | 值得注意的是、在这个时间点 | 直接写事实；“现在”通常已经足够 |
| 23. 过度限定 | 可能潜在地或许会产生一些影响 | 保留一个准确的不确定程度 |
| 24. 万能积极结尾 | 未来可期、迈出重要一步、令人期待 | 写下一项已确定行动、未决问题，或直接收束 |

## 判断优先级

先修事实风险和模糊归因，再修宣传腔与公式结构，最后才处理词频和标点。不要因为某个词出现在表里就机械删除：当它承载准确含义时可以保留，问题在于空泛、重复和无证据使用。
